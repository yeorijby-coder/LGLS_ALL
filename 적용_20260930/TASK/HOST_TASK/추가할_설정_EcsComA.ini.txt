; SRV_MULTI_CONN : 상위(IMS)의 수신 접속을 여러 개 받는다. 기본 1.
;       현장 "접속되자마자 0.1초 만에 통신 쓰레드 종료" 의 원인 - 종전에는 접속 1개용 객체를 모든 접속이
;       같이 써서, 붙어 있는 접속이 있는 채로 새 접속이 오면 옛 스레드의 정리 코드가 새 소켓을 닫았다.
;       구 ECS(ECP TcpServer) 는 접속마다 따로 받았으므로 그와 같게 했다.
;       0 이면 종전처럼 접속 1개만 두고 새 접속이 오면 이전 것을 닫는다(소켓을 서로 닫는 경합만 고침).
SRV_MULTI_CONN = 1

; SRV_STOP_ON_CLI_DBERR : 수신 스레드를 "송신 쪽 DB 오류" 로도 끊던 종전 판정을 쓸지. 기본 0.
;       종전 코드는 송신(Client) 쪽 DB 오류 문구가 남아 있으면 수신 소켓을 말없이 끊고, 지우는 대상이
;       달라 접속마다 되풀이됐다. 이제 수신 스레드는 자기 DB 오류만 보고, 끊을 때 사유를 남긴다.
;       1 이면 비교용 종전 판정(사유는 남긴다).
SRV_STOP_ON_CLI_DBERR = 0
