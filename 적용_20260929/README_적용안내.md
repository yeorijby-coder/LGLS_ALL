붙여넣지 않아도 코드 기본값으로 돌아간다 — 즉 **exe 만 바꿔도 동작한다.**

## 1. 출고 완료가 1~2분 걸리던 것  → `TASK/IO_TASK`

**증상** 자동 출고가 끝났는데 작업이 상태 15 에서 1~2분 머물다 완료됐다.
출고대 준비 신호는 운전 화면에서 확실히 ON 이었다.

**원인** 출고 완료 판정이 네 단계인데, 신호를 믿는 1단계에 두 개의 문턱이 있었다.

| 문턱 | 종전 | 무슨 일이 났나 |
|---|---|---|
| 트래킹 일치 | 출고대의 `LUGG_NO_RD` 가 내 번호이거나 비어 있어야 함 | 앞 화물의 **죽은 번호**가 남아 있으면 신호를 보고도 완료 못 함 |
| 반출 시퀀스 | `OutSeqPending` 이면 판정 자체를 건너뜀 | 시퀀스 잔여 상태가 신호보다 앞섬 |

둘 중 하나만 걸려도 2·3단계(실도착 관측 / 배출 확인)도 못 타고
**4단계 최후 안전망 60초**까지 기다린 끝에 완료됐다. 이것이 "1~2분" 의 정체다.

**고친 것** 출고대 신호를 최우선으로 본다.

- 출고대에 **남의 번호**가 남아 있어도, 그 작업이 `JOB_MST` 에 없으면 유령으로 보고 완료한다
- 살아 있는 다른 작업이면 앞 화물이 아직 안 나간 것이므로 **종전대로 기다린다**
- 신호로 완료가 서면 반출 시퀀스 가드를 건너뛴다
- 신호를 못 본 경우는 **종전 그대로** — 실도착 관측 → 배출 확인 → 60초 안전망

로그에 어느 경로로 완료했는지 남는다.

```
[SCH][CV] 작업 0123 출고대 126 출고대 신호 ON - 출고 완료
[SCH][CV] 작업 0123 출고대 126 트래킹에 끝난 작업 0119 가 남아 있습니다(유령) - 신호로 완료
```

`ENV_IOSCH.INI [CNF] OUT_DONE_BY_SIGNAL = 0` 으로 두면 전부 종전 동작으로 돌아간다.
안전망 시간도 `OUT_SIGNAL_MISS_SEC` 로 뺐다(기본 60 = 1분, 요청대로 유지).

## 2. 신호등 아래 글자 `EQP` → `PLC`  → `Client`

리본 [통신] 그룹의 셋째 칸 이름을 바꿨다. 왼쪽 패널 쪽 표기도 같이 맞췄다.

`EQP_MST` 의 `EQP_TYP` 값은 아직 `'EQP'` 다. 나중에 `'PLC'` 로 바꿀 것을 감안해
**조회는 `'EQP'`·`'PLC'`·`'CV'` 를 모두 같은 칸으로** 본다 — 값을 바꿔도 화면은 그대로 돈다.

## 3. EQP_MST 행을 줄여도 / 안 줄여도 동작  → `TASK/HOST_TASK`, `SQL/`

### 먼저, CLR20r3 의 원인에 대해

행 삭제가 원인이라고 보셨는데, 코드를 다 뒤져 본 결과 **그렇게 보기 어렵다.**
`EQP_MST` 를 쓰는 곳은 네 군데인데 전부 `UPDATE` 이거나 0행을 정상 처리한다.

| 프로그램 | 하는 일 | 0행일 때 |
|---|---|---|
| HOST_TASK `CCliWork` | `SELECT` 후 `iCnt == 0` 분기 있음 | 정상 동작 |
| HOST_TASK `frmMain` | 통신상태 `UPDATE` | 고친 행 0 — 예외 없음 |
| WCS_TASK_CV | 하트비트 `UPDATE` | 〃 |
| IO_TASK | `UPDATE` 하고 없으면 `INSERT` | 스스로 행을 만듦 |

행이 없어서 나는 증상은 **운전 화면 신호등이 미접속으로 보이는 것**이지 프로세스 종료가 아니다.
CLR20r3 는 작업 스레드의 미처리 예외로 보이며, 그에 대한 안전망은 이미 넣어 두었다
(커밋 `ff7d119` — 스레드 하나가 죽어도 프로세스는 살아남는다).
다만 **ALL_TASK 를 쓰지 않기로 하셨으니** 그 위험 자체가 크게 줄었다.

### 그래도 요청대로 옵션을 넣었다

`EcsComA.ini [Host] EQP_MST_AUTO_ROW = 1`(기본)
→ 5초 주기 통신상태 기록에서 **고친 행이 없으면 그 행을 스스로 만든다.**
행을 줄여도 신호등이 정상으로 보이고, 줄이지 않아도 종전대로 돈다.
`0` 이면 `UPDATE` 만 한다(종전 동작).

### SQL 3종 (`SQL/`)

| 파일 | 하는 일 |
|---|---|
| `01_원상복구` | 설비통신 행을 지우고, CV(15)·SC(5)·RTV(1) **21건을 되돌린다** |
| `02_설비통신행_INSERT` | 설비통신 행 1건을 넣는다(있으면 주소만 맞춘다) |
| `03_설비행_정리` | CV/SC/RTV 를 지워 **4행만 남긴다** |

`02` 안의 `@EQP_TYPE` 한 줄만 `'PLC'` 로 고치면 종류 값까지 바꿀 수 있다.
`@WH_TYP` 은 현장 창고 구분에 맞춘다(기본 `'10'`).
여러 번 돌려도 안전하다.

## 4. 범례  → `Client`

### 4.1 뺀 항목

랙투랙 · 호기간 이동 · 반자동 랙투랙 · 반자동 호기간 이동 ·
입고 HS · 출고 HS · 통신두절 · 작업번호 있음 · **레일 관련 전부**
(창고간 이동은 이미 숨겨져 있어 같이 정리했다)

범례 판넬과 범례 설정 창 **양쪽에서** 없앴다. 설정 창은 리소스에서 실제로 지웠고,
4그룹 3행씩 12칸으로 다시 짰다.

남은 것 — 입고/출고/이동, 반자동 입고/출고/이동, 입고대/출고대/일시정지,
에러/수동/검색, (크레인) 정상/수동/에러.

**색 자체는 그대로 쓰인다.** 범례에서만 뺀 것이고, 랙투랙 작업이 들어오면 여전히 그 색으로 칠한다.

### 4.2 화물만 있으면 살색이 되던 이유

`TrackInfo.cpp` 의 `GetCvColor()` 맨 끝에 이런 줄이 있었다.

```cpp
//화물D
if (V_JOB_TYP_RD == "0" && V_SENSOR0_DATA_RD == "1")
    return WHEAT;          // RGB(255,225,192) = 살색
```

**작업구분이 0(작업 없음)이고 화물감지 센서만 켜져 있으면** 살색으로 칠했다.
구 ECS 부터 있던 "작업은 없는데 화물은 놓여 있다" 표시인데,
범례에 없는 색이라 화면에서만 튀었다.

요청대로 이 줄을 없앴다. 이제 화물만 있는 트랙은 **빈 트랙과 같은 회색**이고,
화물이 있다는 것은 트랙 컨트롤의 `m_bExist`(모서리 점 4개)가 그대로 보여 준다.
이 값은 센서를 그대로 받으므로 따로 손댈 것이 없었다.

### 4.3 숨김 체크박스

범례 설정 창의 색상 콤보 **옆에 [숨김] 체크박스**를 뒀다.
체크하고 [저장] 하면 메인 화면 왼쪽 범례 판넬에서 그 줄이 빠지고, 나머지가 당겨진다.
`Ecs.ini [USER] LEGEND_HIDE_*` 에 저장되므로 다시 켜도 유지된다.

동작은 화면으로 확인했다(이동·검색을 숨기니 두 줄이 빠지고 재배치됨).

### 남겨 둔 것 — 도면 안의 "범 례" 표

메인 화면 가운데 도면 위에 **또 하나의 범례 표**가 그려져 있다(랙투랙·HS·레일이 그대로 있다).
이건 왼쪽 판넬과 다른 물건으로, 레이아웃 파일에 도형으로 박혀 있어
코드가 아니라 레이아웃을 고쳐야 한다.

지시하신 범위("범례 판넬·범례 설정 창")에 들어가지 않아 **손대지 않았다.**
9월 15일에 "임베디드 범례 폐기" 로 정리하신 적이 있는데 아직 남아 있다.
지우는 편이 맞다면 말씀해 주시면 레이아웃에서 정리하겠다.

## 5. 4K(3840×2160) 대응  → `Client`

**하나의 Client 로 두 해상도를 다 받는다.** 화면 높이를 보고 배율을 정한다.

| 화면 높이 | 배율 |
|---|---|
| 2160 이상 | 200% |
| 1800 이상 | 175% |
| 1600 이상 | 150% |
| 1300 이상 | 125% |
| 그 미만 | 100% |

리본 [통신] 신호등의 치수·글꼴과 왼쪽 범례 판넬의 치수·글꼴이 이 배율을 따른다.

### 신호등이 2줄(위 3 / 아래 1)로 접히던 이유

MFC 리본은 패널 안을 **행 단위**로 채운다. 신호등 칸이 62×56 픽셀에 박혀 있어서
4K 에서는 상대적으로 작아지고, 그러면 한 패널에 **두 행이 들어갈 여유**가 생겨
MFC 가 4칸을 3+1 로 나눠 담았다. 칸을 화면에 맞게 키우면 한 행만 들어가 다시 한 줄이 된다.
즉 **배율을 키우는 것이 곧 이 문제의 해결**이다.

자동으로 안 맞으면 `Ecs.ini [DISPLAY] UI_SCALE` 에 100~300 을 직접 적는다.
고치면 3초 안에 반영된다(다시 그리는 시점에). 4K 에서 아직 접히면 값을 더 키운다.

## 적용 순서

1. 현장 프로그램·ini 백업
2. TASK 정지 → exe 교체 → `추가할_설정_*.txt` 의 줄을 ini 에 붙여넣기 → 기동
3. Client 는 `Ecs.exe` 만 교체(`[DISPLAY]` 는 넣으면 좋고, 없어도 자동으로 돈다)
4. `SQL/` 은 필요한 것만 — 행을 줄일 때 `02` → `03`, 되돌릴 때 `01`

## 확인하면 좋은 것

- 출고 작업이 출고대 신호 ON 직후에 완료되는가 (IO_TASK 로그에 "출고대 신호 ON - 출고 완료")
- 4K TV 에서 신호등이 한 줄로 나오는가, 글자 크기가 맞는가
- 범례 판넬에 뺀 항목이 안 보이는가, [숨김] 체크가 반영되는가
