; OUT_DONE_BY_SIGNAL : 출고대 신호(RET_READY_RD)를 출고 완료의 최우선 근거로 삼는다.
;       1(기본) 신호가 ON 이면 곧바로 완료. 출고대 트래킹에 이미 끝난 작업번호(유령)가 남아 있어도,
;               반출(RTV) 시퀀스가 아직 안 끝났어도 완료한다.
;       0       종전 동작. 트래킹이 내 번호이거나 비어 있고 반출 시퀀스도 끝나야 완료한다.

; OUT_SIGNAL_MISS_SEC : 출고대 신호도 실도착도 관측하지 못했을 때의 최후 유예(초). 기본 60.
;       화물 트래킹이 전 트랙 어디에도 없는 상태가 이만큼 지속되면 완료로 인정한다(설비 신호 점검 필요).
;       짧게 두면 RGV 하역 직후에 완료되어 버린다 - 5 미만은 5 로 올린다.

; LATCH_TTL_SEC : 출고대 신호 래치가 이만큼(초) 지나도 소비되지 않으면 고아로 보고 지운다. 기본 30.
;       완료를 신호 레벨로 먼저 끝낸 직후, 고속 확인이 아직 켜져 있는 신호를 보고 래치를
;       세우는 일이 있다. 그대로 두면 다음 출고가 도착하기 전에 완료될 수 있어 반드시 지운다.
;       (그 출고대를 기다리는 진행 중 작업이 없으면 이 시간과 무관하게 바로 지운다)
LATCH_TTL_SEC = 30
