> 「반자동 TEST 단위 시험 계획서 V1.0」은 **HOST를 제외한 WCS 내부**(Client·IO_TASK·EQP_TASK·PLC)를 대상으로 한다.

## 1. 시스템 구성

### 1-1. 프로세스 구성

| 계층 | 프로세스 | 실행 파일 | 역할 |
|---|---|---|---|
| 상위 | HOST(WMS) | 고객사 시스템 / `SIM/HOST_SIM` | 입·출고 지시, 결과 수신 |
| 인터페이스 | HOST_TASK | `TASK/WCS_TASK_HOST` | WMS 전문 송수신, DB 반영 |
| 스케줄 | IO_TASK | `TASK/IO_TASK/bin/Debug/IO_TASK_SEMI_FINISH.exe` | 작업 상태 전이, 설비 지시 생성 |
| 설비통신 | EQP_TASK | `TASK/WCS_TASK_CV_BIN/bin/Debug/WCS_TASK_CV.exe` | 마스터 PLC 1소켓(FEnet), C/V·S/C·RGV |
| 설비 | PLC | 실 PLC / `SIM/EQP_SIM` | 컨베이어 15대, S/C 5대, RGV 1대 |
| 운영 | Client | `WCS/CPlusPlus/LGLS_CLIENT/Bin/Debug/Ecs.exe` | 모니터링, 수동 작업, 반자동 TEST |
| 데이터 | DB | SQL Server `LGLS_MCS_IO` | 전 프로세스의 유일한 공유 지점 |

### 3-2. 기동 순서

```
① DB 기동 확인
② EQP_SIM (또는 실 PLC 링크 확인)
③ HOST_SIM (또는 실 WMS 연동 승인)
④ EQP_TASK      ← 기동 로그에서 PLC 접속 성공 확인
⑤ IO_TASK
⑥ HOST_TASK     ← HOST 접속 성공 확인
⑦ Client (Ecs)  ← tools\Start-WcsClient.ps1
⑧ TEST 초기화(시험계 한정)
```

### 3-3. DB 초기 상태 — `UT` 계획서 2-2 절과 동일

`JOB_MST` 정리, `CV_DATA`/`SC_DATA_LGLS`/`RTV_DATA_LGLS` 초기화.
`ITN_LUGG_FK2` 는 반드시 `'0'` (빈 문자열이면 S/C 지시가 영구 차단된다).

## 4. 시험 항목

각 항목은 **절차 → 기대결과 → 판정근거**로 구성한다.
판정근거는 화면 캡처 · DB 조회 · 프로세스 로그 중 하나 이상으로 객관 확인이 가능해야 한다.

### 4-1. A군 — HOST(WMS) 인터페이스 (HIF)

전문 규격 : 인터페이스명세서(20100311) = 1WH ECP 규격.
BODY 길이 — 입고지시 `O` 66B · 출고지시 `R` 31B · 모드변경 `M` 7B · 상태보고 `S` 43B · 에러보고 `E` 23B · 완료보고 `F` 10B · 응답 11B.

| # | 항목 | 절차 | 기대결과 | 판정근거 |
|---|---|---|---|---|
| HIF-01 | 접속·해제 | HOST_TASK 기동 → HOST 접속 → 강제 해제 → 재접속 | 접속 성립, 해제 감지, 자동 재접속 | HOST_TASK 화면·로그 |
| HIF-02 | 입고지시 `O` 수신 | HOST에서 입고지시 송신 | `JOB_MST` 에 `JOB_TYP=11` 신규 행, 응답 전문 정상 회신 | `JOB_MST` / IF 로그 |
| HIF-03 | 출고지시 `R` 수신 | 출고지시 송신 | `JOB_TYP=12` 신규 행 생성 | 〃 |
| HIF-04 | 작업삭제 `D` 수신 | 진행 전 작업에 삭제 지시 | 해당 작업 삭제, 진행 중이면 규정된 거부 응답 | 〃 |
| HIF-05 | 모드변경 `M` 수신 | 입출고대 방향 모드 변경 지시 | C/V 방향 워드가 바뀌고 반대방향 작업이 없을 때만 전환 | `CV_DATA` / PLC 방향 워드 |
| HIF-06 | 상태보고 `S` 송신 | 설비 상태 변화 유발 | 43B 집계 단일 전문으로 주기 송신, 트랙 122/126/129/130 상태 반영 | 송신 로그 캡처 |
| HIF-07 | 완료보고 `F` 송신 | 입고 1건 완료 | 완료 전문 송신, `StepCount` 규격 준수 | 〃 |
| HIF-08 | 도착보고 | 1차 완료 시점 | `F` + `StepCount=1` 로 보고(명세에 `A` 전문 없음) | 〃 |
| HIF-09 | 에러보고 `E` 송신 | 이중입고 유발 | 에러 전문 송신, 에러종별 코드 매핑 정확 | 〃 |
| HIF-10 | 공파렛트 요구 `N` | 공파렛트 조건 성립 | `N` 전문 송신 | 〃 |
| HIF-11 | 작업대 번호 변환 | 트랙 122/129·130/126 로 작업 발생 | 상위 규격 번호(101~104)로 변환되어 송신 | 송신 전문 대조 |
| HIF-12 | 미지원 전문 | 정의되지 않은 MsgType 송신 | `X` 응답 + `UNKNOWN_MSG_TYPE`, 프로세스 계속 동작 | 로그 |
| HIF-13 | 전문 길이 오류 | BODY 길이를 규격과 다르게 송신 | 거부 응답, 오동작·다운 없음 | 로그 |
| HIF-14 | 재기동 중 지시 | HOST_TASK 정지 중 지시 → 기동 | 미수신분 손실 처리 규칙대로 동작(재송 또는 누락 기록) | 로그·DB |

| A(치명) | 작업 유실·설비 손상·전 구간 정지 | 즉시 수정, 해당 단계 전체 재시험 |

| C(경미) | 표시·문구·편의성 | 기록 후 일괄 조치, 재시험은 해당 항목만 |

결함 기록 항목 : 발견일 · 항목번호 · 현상 · 재현절차 · 근거(캡처/로그) · 등급 · 담당 · 조치일 · 재시험 결과.

## 8. 확인용 SQL

-- 진행 중 작업 전체
SELECT LUGG_NO, START_POS, START_LOCATION, DEST_POS, DEST_LOCATION,
       JOB_TYP, JOB_STATUS, REMARKS, INS_DT
  FROM JOB_MST ORDER BY INS_DT;

  FROM JOB_MST WHERE DATEDIFF(second, UPD_DT, GETDATE()) > 60;

  FROM SC_DATA_LGLS WHERE sc_no BETWEEN '901' AND '905';
SELECT rtv_no, subsystem_status_rd, lugg_od, cmd_rq_yn FROM RTV_DATA_LGLS;

-- 작업대/트랙 (로직3=122 · 로직1=126/124 · 로직2=130/129)

       SENSOR0_DATA_RD, STO_READY_RD, RET_READY_RD
  FROM CV_DATA WHERE MC_NO IN ('121','122','123','124','125','126','129','130','131','132');

-- 완료 이력
SELECT TOP 50 LUGG_NO, JOB_TYP, DEST_LOCATION, INS_DT
  FROM JOB_MST_HIS ORDER BY INS_DT DESC;

SELECT CELL_NO, CELL_SC_NO, USE_YN, LUGG_NO FROM CELL_MST WHERE USE_YN = 'Y';
