# IMS(WMS) Station 번호 ↔ 트랙번호 매칭표

LG 화학 1동 자동창고 (WH_TYP = 10) · 2026-09-09 기준

상위(IMS/WMS)가 전문에 싣는 **스테이션 코드**와 WCS 내부의 **설비/트랙 번호**를 잇는 표다.
변환은 `TASK/WCS_TASK_HOST/modStationMap.cs` 한 곳에서만 한다.

- **WCS 내부코드 = 100 + 트랙번호** (TR#22 → 122), 크레인은 **901~905**
- 적용 기준은 `EcsComA.ini` `[Host] StationMapMode` (`WMS` | `ECS`, **기본 WMS**)
- 개별 코드는 `[StationMap_WMS]` / `[StationMap_ECS]` 에서 재정의 가능 (재컴파일 불필요)
  - 표기 : `IMS코드 = 출발내부코드 , 도착내부코드` (하나만 쓰면 출발·도착 동일)

---

## 1. 작업대 (현행 = WMS 기준)

| IMS 코드 | 명칭 | 내부코드(출발) | 내부코드(도착) | 트랙 | 설비 | 비고 |
|---:|---|---:|---:|---:|---|---|
| 101 | 외부 입고 전용 입출고대 | 122 | 122 | TR#22 | C/V#11 | 입출고 겸용(방향전환) |
| 102 | Picking 작업대 | **130** | **129** | TR#30 / TR#29 | C/V#15 / C/V#14 | ★출발·도착 트랙이 다르다 |
| 103 | 제품 입고대 | 124 | 124 | TR#24 | C/V#12 | |
| 104 | 원부자재 불출대 | 126 | 126 | TR#26 | C/V#13 | |
| 105 | (확장) C/V#2 통로 | 103 | 103 | TR#3 | C/V#2 | 시뮬 방향전환용. 현장 WMS 는 보내지 않음 |
| 110 | 실온 S/C#1 통로 C/V | 103 | 103 | TR#3 | C/V#2 | C/V IO 모드 전환(M 전문) 전용 |

### 102(Picking 작업대)가 출발·도착이 다른 이유

WMS 는 피킹존을 **하나의 작업대**로 보지만, 설비는 방향별로 트랙이 갈린다.

- 피킹 **출고 도착** → TR#29 (C/V#14) — 경로정의·작업이력 모두 존재 (902/903 → 129, 14,244건)
- 피킹 **재입고 출발** → TR#30 (C/V#15) — 130 → 901/902/903, 19,013건
- TR#29 에서 **출발**하는 입고 작업은 이력 0건이고 경로정의도 없다
  (C/V#14 는 127→129 출고 흐름만, C/V#15 가 130→131 입고 흐름을 가진다)

→ 상위 **보고 시에는 129·130 을 모두 102 로 되돌린다** (WMS 는 130 을 모른다).

## 2. 하이랙 크레인 (두 기준 공통)

| IMS 코드 | 내부코드 | 설비 | 비고 |
|---:|---:|---|---|
| 001~005 | 901~905 | S/C#1~5 | 인터페이스 명세서 표기 |
| 201~205 | 901~905 | S/C#1~5 | 구 ECS DB 표기 |

수신은 **두 표기를 모두 받는다**. 상위 보고(역변환)만 기준에 따라 갈린다.

| StationMapMode | 901~905 보고 값 |
|---|---|
| `WMS` (기본) | 001~005 |
| `ECS` | 201~205 |

> WMS 운영 DB 의 크레인 코드는 미확인 항목이다. 상위와 값이 어긋나면
> `[StationMap_WMS]` 의 `001=` ~ `005=` 항목으로 조정한다.

## 3. ECS 기준 (참고 — `StationMapMode=ECS` 일 때)

구 ECS 구축시드 DB(`LglsMCS.TB_CODEMASTER` `CODECLASS='022'`, 2010~2011) 배정이다.
**현행 운영은 WMS 기준이므로 아래는 쓰지 않는다.**

| IMS 코드 | 내부코드 | 트랙 | 설비 |
|---:|---:|---:|---|
| 101 | 122 | TR#22 | C/V#11 입출고대 |
| 102 | 124 | TR#24 | C/V#12 입고대 |
| 103 | 126 | TR#26 | C/V#13 출고대 |
| 104 | 129 | TR#29 | C/V#14 피킹 출고대 |
| 105 | 130 | TR#30 | C/V#15 피킹 입고대 |

### 두 기준의 차이

| IMS | WMS 기준 (현행) | ECS 기준 |
|---:|---|---|
| 102 | 피킹 작업대 (130/129) | C/V#12 입고대 (124) |
| 103 | 제품 입고대 (124) | C/V#13 출고대 (126) |
| 104 | 원부자재 불출대 (126) | C/V#14 피킹 출고대 (129) |
| 105 | (확장) C/V#2 | C/V#15 피킹 입고대 (130) |

> 103/104 는 2026-08-24 협의로 **설비 용도 기준**(103=124 제품입고 / 104=126 원부자재불출)으로
> 정했다. 종전 작업이력 기준(103=126 / 104=124)으로 되돌리려면
> `[StationMap_WMS]` 에 `103=126` `104=124` 를 넣는다.

## 6. 확인 방법

```sql
-- 트랙 ↔ 설비 대응
SELECT mc_no, plc_no, mc_no_nm FROM cv_data ORDER BY CAST(mc_no AS int);

-- 출고 목적지
SELECT * FROM dest_pos_def;
```

적용 중인 기준은 **HOST 통신 창을 켤 때 로그 첫 줄**에 찍힌다
(`modStationMap.DumpMap()` → `[스테이션 매핑 기준] WMS(WMS 운영DB 기준) 101→122 …`).
