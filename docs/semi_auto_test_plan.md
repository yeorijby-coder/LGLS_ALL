## 1. 시험 대상과 범위

### 1-1. 대상 프로그램

| 구분 | 실행 파일 | 역할 |
|---|---|---|
| Client | `WCS/CPlusPlus/LGLS_CLIENT/Bin/Debug/Ecs.exe` | 반자동 TEST 창 — 작업 생성/삭제, 교신 로그 |
| IO_TASK | `TASK/IO_TASK/bin/Debug/IO_TASK_SEMI_FINISH.exe` | 작업 스케줄링(상태 전이 99→…→29/19) |
| EQP_TASK | `TASK/WCS_TASK_CV_BIN/bin/Debug/WCS_TASK_CV.exe` | PLC 통신(C/V·S/C·RGV), 주소맵 XML 적용 |
| PLC | `SIM/EQP_SIM/bin/Debug/EQP_SIM.exe` **또는 실 PLC** | 설비 거동 |
| (미기동) | HOST_TASK / HOST_SIM | **반자동은 HOST와 무관** — 기동하지 않는다 |

### 1-2. 범위에 포함

- 반자동 TEST 창의 전 기능(모드 2종, 시작/정지, 로그)
- 반자동 작업의 전 구간 흐름(입고 99→11→15→30→35→20→21→25→29 / 출고 →19)
- 주소맵 XML(`PlcAddressMap.xml`) 적용 여부와 전환 반영
- R 영역 주소모드(구ECS 16진 / 현행 10진) 전환

### 1-3. 범위에서 제외

- HOST(WMS) 연동 전문 송수신 → 별도 HOST 시험
- 실 PLC 래더 동작 자체의 적합성
- Client 다국어/스킨 등 UI 외관

## 2. 사전 조건

### 2-1. 환경 설정 확인 (시험 전 반드시 점검)

| # | 파일 | 항목 | 값 | 확인 |
|---|---|---|---|---|
| 1 | `TASK/WCS_TASK_CV_BIN/bin/Debug/WCS_DB.INI` | `[COMM0] IP` | 시뮬레이터 시험 = `127.0.0.1` / 현장 = `192.100.1.120` | ☐ |
| 2 | 〃 | `[PROCESS] CNT` | `1` (마스터 PLC 1소켓) | ☐ |
| 3 | 〃 | `[PLC] R_ADDR_MODE` | `HEX`(구ECS 호환) 또는 `DEC`(현행) — 현장에 맞춤 | ☐ |
| 4 | `TASK/WCS_TASK_CV_BIN/bin/Debug/7_DeviceMap/PlcAddressMap.xml` | 존재 및 문법 | 메모리 맵 창 제목에 `주소맵 XML v1.3 적용` 표시 | ☐ |
| 5 | `SIM/EQP_SIM/bin/Debug/EQP_SIM.ini` | `[FEED] AUTO` | `1`, `CV11/CV12/CV15=1` (입고대 자동 투입) | ☐ |
| 6 | `WCS/CPlusPlus/LGLS_CLIENT/Bin/Debug/Ecs.ini` | `[MENU] SEMITEST_MENU` | `1` (반자동 TEST 메뉴 표시) | ☐ |

> ⚠ **시뮬레이터로 시험한 뒤에는 `[COMM0] IP`를 반드시 현장값으로 되돌린다.**

### 2-2. DB 초기 상태

Client 리본 **[Manual] → [TEST 초기화]** 실행 (확인창 → 예)

- `JOB_MST` 전체 삭제
- `CV_DATA` : `LUGG_NO_RD='0000'`, `JOB_TYP_RD='0'`, `DEST_POS_RD='000'`, `ERROR_CODE='0'`
- `SC_DATA_LGLS` : `ITN_LUGG_FK1/FK2='0'`, `LUGG_NO_FK1_OD='0'`, `CMD_RQ_YN='N'`, `HOST_SEND_YN='N'`
- `RTV_DATA_LGLS` : `LUGG_OD='0'`, `JOB_TYP_OD='0'`, `CMD_RQ_YN='N'`

> `ITN_LUGG_FK2`는 반드시 `'0'` (빈 문자열이면 SC 지시가 영구 차단됨)

### 2-3. 기동 순서

```
① EQP_SIM (또는 실 PLC 연결 확인)
② IO_TASK
③ EQP_TASK        ← 기동 로그에서 PLC 접속 성공 확인
④ Client (Ecs)    ← tools\Start-WcsClient.ps1
⑤ TEST 초기화
⑥ 반자동 TEST 창 열기
```

## 3. 시험 항목

각 항목은 **절차 → 기대결과 → 판정근거**로 구성한다. 판정근거는 화면·DB·로그 중 하나 이상으로 객관 확인이 가능해야 한다.

### UT-01. 반자동 TEST 창 열기/닫기

| | 내용 |
|---|---|
| 절차 | 리본 [Manual] → [반자동 TEST] 클릭 |
| 기대 | 창이 열리고 5행(출발지/도착지/로케이션/SC1~5/상태)이 표시된다. 창 크기 조절이 가능하다. |
| 판정 | 화면 캡처. 리사이즈 시 버튼 크기가 유지되고 로그 리스트가 함께 늘어난다. |

### UT-02. 자동 로케이션 모드 — 입고 1사이클

| | 내용 |
|---|---|
| 절차 | 라디오 **[자동 로케이션]** 선택 → 1행 출발지 `126`, 도착지 `124`, **SC1 체크** → [시작] |
| 기대 | ① 작업 생성(`JOB_TYP=11`) ② 상태 `99→11→15→30→35→20→21→25→29` 순차 전이 ③ 완료 시 **HOST 보고 없이 삭제** |
| 판정 | 창 로그의 상태전이 행 / `SELECT JOB_STATUS FROM JOB_MST WHERE REMARKS LIKE 'SEMITEST%'` |

### UT-03. 자동 로케이션 모드 — 출고 연계

| | 내용 |
|---|---|
| 절차 | UT-02에 이어서 관찰 |
| 기대 | 입고 완료 직후 **같은 셀에서 출고 작업(`JOB_TYP=12`)** 이 자동 생성되고, `19` 도달 시 삭제된다 |
| 판정 | 로그 `작업생성(출고)` 행 + `JOB_STATUS 15 → 19` |

### UT-04. 셀 자동 증가

| | 내용 |
|---|---|
| 절차 | 3사이클 이상 연속 관찰 |
| 기대 | 입고 셀이 `01-001-01 → 01-001-02 → …` 로 **CELL_MST의 CELL_NO 순서대로 증가**하고, 끝에 도달하면 처음으로 돌아간다 |
| 판정 | `SELECT DEST_LOCATION FROM JOB_MST` 이력 / 로그의 `작업생성(입고)` 내용 |

### UT-05. 크레인 라운드로빈

| | 내용 |
|---|---|
| 절차 | 1행에 **SC1·SC3 두 개 체크** 후 시작 |
| 기대 | 사이클마다 크레인이 번갈아 선택된다(901 → 903 → 901 …) |
| 판정 | 로그 `작업생성(입고)` 의 `SC90x` 표기 순서 |

### UT-06. 로케이션 직접 입력 모드

| | 내용 |
|---|---|
| 절차 | 라디오 **[로케이션 직접 입력]** 선택 → 1행 로케이션에 `01-001-05` 입력 → [시작] |
| 기대 | ① 입력 셀의 담당 크레인이 `CELL_MST.CELL_SC_NO`로 자동 판별 ② **같은 셀로 입·출고 무한 반복**(자동 증가 없음) |
| 판정 | `SELECT DEST_LOCATION, DEST_POS FROM JOB_MST` — 항상 `01-001-05` / `901` |

### UT-07. 로케이션 입력 형식 허용

| | 내용 |
|---|---|
| 절차 | `01-001-05` / `01.001.05` / `01 001 05` / `0100105` 각각 입력 |
| 기대 | 네 형식 모두 동일 셀로 해석된다 |
| 판정 | 각 입력마다 생성된 `DEST_LOCATION` 이 `01-001-05` |

### UT-08. 잘못된 로케이션 처리

| | 내용 |
|---|---|
| 절차 | 존재하지 않는 셀(`99-999-99`) 입력 후 시작 |
| 기대 | 작업을 만들지 않고 **로그에 사유를 남긴다**(`CELL_MST 에 없는 로케이션입니다`). 프로그램은 계속 동작. |
| 판정 | 창 로그 / `JOB_MST` 에 신규 행 없음 |

### UT-09. 정지 = 드레인

| | 내용 |
|---|---|
| 절차 | 작업 진행 중 [정지] 클릭 |
| 기대 | **즉시 중단이 아니라** 진행 중인 작업만 완료·삭제하고 새 작업을 만들지 않는다. 모든 행이 대기가 되면 `정지 완료` 로그. |
| 판정 | 로그 `정지 요청 - 진행 중인 작업 완료 후 종료합니다` → `정지 완료` / `JOB_MST` 잔여 0건 |

### UT-10. 반자동 원칙 — HOST 보고 금지

| | 내용 |
|---|---|
| 절차 | (HOST_TASK를 기동한 상태에서) 반자동 1사이클 수행 |
| 기대 | 완료 시 **HOST로 완료(F)/도착 보고를 보내지 않고** JOB만 삭제된다 |
| 판정 | HOST_TASK 송신 로그에 해당 작업번호(9xxx) 전문 없음. 로그 `완료 → 삭제 (반자동: HOST 보고 없음)` |

### UT-11. 교신 로그 컬럼

| | 내용 |
|---|---|
| 절차 | 사이클 진행 중 로그 관찰 |
| 기대 | 날짜/시간/로직/동작/작업번호/**시스템**/**함수명**/내용 8컬럼이 채워진다. 시스템은 `Client`·`IO_SCH`·`EQP_TASK` 중 하나이며 함수명이 실제 구현 함수와 일치한다. |
| 판정 | 화면 캡처 — 예: `IO_SCH / cThread_SCH.DriveCV / JOB_STATUS 10 → 11` |

### UT-12. 주소맵 XML 적용 확인

| | 내용 |
|---|---|
| 절차 | EQP_TASK → [PLC 메모리 맵] 창 제목 확인 → [주소맵 XML] 탭 |
| 기대 | 제목에 `[주소맵 XML v1.3 적용 (3군 / 시나리오 7개)]`, 탭에 XML 전문과 파일 경로 표시 |
| 판정 | 화면 캡처 |

### UT-13. 주소맵 XML 전환 반영

| | 내용 |
|---|---|
| 절차 | [주소맵 XML] 탭에서 `<Block name="Event" … origin="256">` 을 `288` 로 변경 → [저장 + 적용] → Bit 탭 확인 → 원복 |
| 기대 | 재빌드·재기동 없이 Bit 탭 주소가 `%MX288~` 로 바뀐다. 원복 시 되돌아온다. **문법을 깨면 저장되지 않고 사유를 알린다.** |
| 판정 | Bit 탭 캡처 2매(변경 전/후), `.bak` 파일 생성 |

### UT-14. SC/RGV 주소 XML 단일화

| | 내용 |
|---|---|
| 절차 | `observables.tsv` 를 임시로 이름 변경 후 EQP_TASK 재기동 |
| 기대 | SC 5대·RGV 1대의 `subsystem_status_rd` 가 정상(`1`)으로 갱신된다 — **tsv 없이 XML만으로 동작** |
| 판정 | `SELECT sc_no, subsystem_status_rd FROM SC_DATA_LGLS` / `RTV_DATA_LGLS` |

### UT-15. R 주소모드 전환

| | 내용 |
|---|---|
| 절차 | EQP_TASK 상단 라디오 `R:16진(구ECS)` ↔ `R:10진(현행)` 전환 |
| 기대 | ① `WCS_DB.INI` 의 `R_ADDR_MODE` 가 즉시 바뀐다 ② 열려 있는 메모리 맵의 Tracking 탭이 자동 갱신된다(`R0100` → `%RB512` ↔ `%RB200`) |
| 판정 | INI 파일 / Tracking 탭 캡처 2매 |

### UT-16. 시나리오 테스트 XML 다시 읽기

| | 내용 |
|---|---|
| 절차 | XML의 `<Scenario>` 하나를 수정/삭제 → 시나리오 창 [주소맵 XML 다시 읽기] |
| 기대 | 창을 닫지 않고 시나리오 버튼 목록과 상단 카운트가 갱신된다 |
| 판정 | 화면 캡처 2매(전/후) |

### UT-17. 장시간 연속 운전

| | 내용 |
|---|---|
| 절차 | 자동 로케이션 모드로 **50사이클 이상** 연속 수행 |
| 기대 | 정체·중복·유령 작업 없이 계속 순환한다. 메모리/핸들 증가로 인한 이상이 없다. |
| 판정 | `REMARKS` 순번 증가(`SEMITEST-R1-nn`), `JOB_MST` 잔여 1건 이하 유지 |

### UT-18. 다중 행 동시 운전

| | 내용 |
|---|---|
| 절차 | 1행(SC1) + 2행(SC3) 동시 설정 후 시작 |
| 기대 | 두 행이 독립적으로 순환하며 서로 간섭하지 않는다 |
| 판정 | `REMARKS` 가 `SEMITEST-R1-*` / `SEMITEST-R2-*` 로 병행 증가 |

## 7. 참고 — 확인용 SQL

```sql
-- 진행 중 반자동 작업
SELECT LUGG_NO, START_POS, START_LOCATION, DEST_POS, DEST_LOCATION,
       JOB_TYP, JOB_STATUS, REMARKS
  FROM JOB_MST WHERE REMARKS LIKE 'SEMITEST%';

-- 설비 상태 (XML 주소 적용 확인)
SELECT sc_no, subsystem_status_rd, itn_lugg_fk1, itn_lugg_fk2, read_upd_dt
  FROM SC_DATA_LGLS WHERE sc_no BETWEEN '901' AND '905';
```
