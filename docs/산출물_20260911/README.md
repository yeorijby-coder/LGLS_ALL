### V1.3 에서 바뀐 것

- **[INI 열기] 버튼을 숨겼다** — 화면에는 있는데 목차에 없던 항목이다.
  `Ecs.ini [MENU] INI_MENU=0`.
- **범례 글자를 칸에 맞췄다** — 칸을 넘쳐 잘리던 5개를 `fontsize="0"`(칸 맞춤)으로.
  실측(Arial Bold, lfHeight=12, 배율 26px/논리단위) 기준 넘치던 것 :
  반자동 호기간이동(-28) / 호기간이동(-15) / 작업없음(정상)(-9) /
  반자동 랙투랙(-4) / 일시정지(-3).
- **RTV 배치 수정** — 현장 시험에서 RTV 가 103 제품 입고대로 왔는데 화면에는 한 칸
  덜 온 것으로 그려졌다. 트랙 23·24·25·26 과 라벨(103/104), CV#12·CV#13 표기를
  한 칸 내리고 RTV 레일을 한 칸 더 뻗도록 재배치했다.
- 위 세 가지가 반영된 상태로 `main_0` / `panels_0` / `panels_all` 3장을 다시 찍었다.

캡처는 종전과 같은 조건(**작업 없는 상태**)으로 맞췄다. 전체 초기화 후 HOST 를
올리기 전에 찍고, 찍은 뒤 HOST_SIM [시작] 을 눌러 구동을 재개한다.
