## 다시 만들려면

```
cd docs\산출물_20260927\gen
python gen_screen_pptx.py       # 06 화면설계서
python gen_guide_docx.py        # 05 운전 지침서
python gen_usermanual_docx.py   # 13 사용자 매뉴얼
python gen_ini_docx.py          # 12 INI 설정 정의서 (현재값은 실행 폴더 INI 를 읽는다)
```

- `gen_screens.py` 가 화면 목록·설명의 원본이다. 05 와 06 이 이 파일을 함께 읽는다.
  여기서 항목을 덜어내면 두 문서의 장 번호가 함께 맞춰진다.
- 캡처는 `shots\`. 창을 `WM_COMMAND`(리본 버튼 ID)로 열고 `PrintWindow` 로 담는다.
  **창이 늦게 떠서 직전 창을 잡는 일이 있으니 제목으로 확인**한다(09-27 에 범례·수동지시가 바뀐 원인).
- 이 폴더의 `06_ECS_화면설계서.pptx` 는 생성기가 정식 이름으로 저장한다.
  (09-17·09-21 판 폴더의 같은 파일은 사용자 수정본이라 `_gen.pptx` 로만 저장한다 - 그쪽은 건드리지 않는다.)

## 관리자 매뉴얼 (예정)

서버 프로그램(TASK) 화면은 이 판에서 뺐다. 다음 문서에 들어갈 내용 :
