# WCS DB 서버 이관 절차 (2026-09-02)

백업 파일 (이 폴더):
- `LGLS_MCS_IO_20260902.bak` — 신 WCS DB (약 611MB, 로그 테이블 포함)
- `LglsMCS_20260902.bak` — 구 ECS DB (약 2.8MB)

---

## 1. 파일 복사
두 .bak 파일을 서버 PC로 복사한다. 예: `C:\Backup\`
(SQL 서비스 계정이 읽을 수 있는 로컬 경로여야 한다. 네트워크 경로는 피할 것)

## 2. SSMS에서 복원
1. SSMS 실행 → 서버 인스턴스 접속 (관리자)
2. 개체 탐색기에서 [데이터베이스] 우클릭 → [데이터베이스 복원...]
3. [디바이스] 선택 → [...] → [추가] → `C:\Backup\LGLS_MCS_IO_20260902.bak`
4. 대상 데이터베이스 이름이 `LGLS_MCS_IO` 인지 확인
5. [파일] 페이지에서 데이터/로그 파일 경로가 서버의 데이터 폴더인지 확인
   (기본값이면 그대로 OK. "다음으로 이동" 체크로 자동 재배치)
6. 확인 → 복원 완료
7. `LglsMCS_20260902.bak` 도 같은 방법으로 복원 (구 ECS도 서버 DB를 쓸 경우)

또는 쿼리로:
```sql
RESTORE DATABASE [LGLS_MCS_IO]
  FROM DISK = 'C:\Backup\LGLS_MCS_IO_20260902.bak'
  WITH MOVE 'LGLS_MCS_IO'     TO 'C:\Program Files\Microsoft SQL Server\...\DATA\LGLS_MCS_IO.mdf',
       MOVE 'LGLS_MCS_IO_log' TO 'C:\Program Files\Microsoft SQL Server\...\DATA\LGLS_MCS_IO_log.ldf',
       REPLACE, STATS = 10;
```
(논리 파일명 확인: `RESTORE FILELISTONLY FROM DISK='C:\Backup\...bak'`)

## 3. 혼합 인증 + 접속 계정 생성
SSMS: 서버 우클릭 → 속성 → 보안 → **"SQL Server 및 Windows 인증 모드"** 선택 → 확인
→ **SQL 서비스 재시작** (구성 관리자 또는 SSMS에서 서버 우클릭 → 다시 시작)

새 쿼리:
```sql
CREATE LOGIN mcsuser WITH PASSWORD = '비밀번호', CHECK_POLICY = OFF;

USE LGLS_MCS_IO;
CREATE USER mcsuser FOR LOGIN mcsuser;
EXEC sp_addrolemember 'db_owner', 'mcsuser';

USE LglsMCS;   -- 구 ECS DB도 복원했다면
CREATE USER mcsuser FOR LOGIN mcsuser;
EXEC sp_addrolemember 'db_owner', 'mcsuser';
```
(sa를 쓰지 말고 전용 계정 권장. sa는 `ALTER LOGIN sa DISABLE;` 로 잠가두는 것을 권함)

## 4. 원격 접속 허용
1. **SQL Server 구성 관리자** → SQL Server 네트워크 구성 → 해당 인스턴스 프로토콜
   → **TCP/IP 사용** → TCP/IP 속성 → IP 주소 탭 → IPAll:
   TCP 동적 포트 = (비움), **TCP 포트 = 1433**
2. SQL 서비스 재시작
3. 방화벽:
```
netsh advfirewall firewall add rule name="MSSQL 1433" dir=in action=allow protocol=TCP localport=1433
```

## 5. 접속 확인 (클라이언트 PC에서)
```
sqlcmd -S 서버IP,1433 -U mcsuser -P 비밀번호 -d LGLS_MCS_IO -Q "SELECT COUNT(*) FROM JOB_MST"
```

## 6. 각 프로그램 접속 설정 변경 (클라이언트 PC)
| 프로그램 | 파일 | 항목 |
|---|---|---|
| WCS_TASK_CV | bin\Debug\WCS_DB.INI | [DB] 접속 IP/계정 (INI 열기 버튼으로 열기) |
| IO_TASK | bin\Debug\ENV_IOSCH.INI | 〃 |
| WCS_TASK_HOST | bin\Debug\EcsComA.ini | [DB] IP=서버IP,1433 + 계정 |
| Ecs Client | (접속 INI) | 〃 |
| 구 ECS | OldECS\HECS.exe.config | StartMode=Client, GlobalDataBaseConnectionString → `Data Source=서버IP,1433;Initial Catalog=LglsMCS;User ID=mcsuser;Password=...` |

## 주의
- LGLS_MCS_IO 백업이 611MB로 큰 것은 통신/작업 로그 테이블 누적분. 이관 전
  로그 테이블 정리(DELETE 후 SHRINK) 하면 수십 MB 로 줄일 수 있음 (원하면 요청).
- 서버 SQL이 Express 가 아니면 복원 시 압축/버전 문제 없음. 단 **서버 SQL 버전이
  개발 PC(SQLEXPRESS)보다 낮으면 복원 불가** — 같거나 높아야 한다.
